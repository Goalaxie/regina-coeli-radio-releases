# Regina Cœli Radio — application Android

Écoutez Regina Cœli Radio, 94.6 MHz à Kasindi, et retrouvez ses podcasts, journaux, vidéos et articles.

[**Télécharger la dernière version Android**](https://github.com/Goalaxie/regina-coeli-radio-releases/releases/latest)

## Installation

1. Ouvrez la dernière release et téléchargez le fichier **Regina-Coeli-Radio-v1.0.0-universal.apk** dans la section **Assets**.
2. Ouvrez le fichier téléchargé sur votre téléphone Android.
3. Si Android le demande, autorisez votre navigateur à installer cette application, puis confirmez l’installation.

**Compatibilité : Android 7.0 ou version ultérieure.** Une seule APK couvre les appareils ARM 32 bits, ARM 64 bits, x86 et x86_64. Il ne s’agit pas d’une application iPhone.

Pour les prochaines mises à jour, installez la nouvelle APK par-dessus la version précédente. Les versions de distribution conservent la même signature.

Le fichier **SHA256SUMS.txt**, joint à chaque release, permet de vérifier l’intégrité du téléchargement.
